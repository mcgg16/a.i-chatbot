* Install project
* Run with: npx http-server ./frontend

* Add the script to float messages to left or right depending on who sent it 
* Run: npm install express // Helps install files to handle api requests 
* Run: npm install body-parser cors
  * body-parser to parse the mssg that was sent 
  * Cross-origin resource sharing (CORS) is a mechanism for integrating applications. CORS defines a way for client web applications that are loaded in one domain to interact with resources in a different domain.
* Create server.js because it is set as the main in package.json. Add the project dependencies, middleware, body parser
* Run with: node server.js

* Go to backend and run: npm install dotenv
* Then create .env file in backend, add var like OPENAI_API_KEY and copy paste the string key

* Create base routes with the "/" and req, res

* Install open AI library run: npm install openai
* Set the Configuration and pass it to the OPENAI_API_KEY
* Custom the /message to specify what ai model is being used, role, content, etc., and then get the result. 
* Cannot run from browser rn, but use tool like postman, localhost:1330/message and then click send to see what the result is
